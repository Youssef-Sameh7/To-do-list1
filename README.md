# To-do-list1
TaskFlow - To-Do List

📌 Description

TaskFlow is a simple and responsive To-Do List and Task Management Website.

The website helps users organize their tasks by adding a task name and a required due date. Users can also manage their tasks by completing, editing, deleting, and filtering them.

The project has a clean and modern design with different colors for each task status.

---

✨ Features

- ➕ Add a new task.
- 📝 Enter a task name.
- 📅 Set a required due date.
- 🚫 Prevent adding a task without a date.
- 🚫 Prevent selecting an old date.
- ✅ Mark tasks as completed.
- ✏️ Edit tasks.
- 🗑️ Delete tasks.
- 🔍 Filter tasks by status.
- 🟡 Display pending tasks.
- 🟢 Display completed tasks.
- 🔴 Automatically detect overdue tasks.
- 💾 Save tasks using LocalStorage.
- 📱 Responsive design for mobile, tablet, and desktop.
- 🎨 Modern and consistent color scheme.

---

📊 Task Status

🟡 Pending

The task has not been completed and its deadline has not passed.

🟢 Completed

The task has been marked as completed by the user.

🔴 Overdue

The deadline has passed and the task has not been completed.

---

💾 LocalStorage

TaskFlow uses the browser's LocalStorage to store tasks.

This allows the user's tasks to remain saved after:

- Refreshing the page.
- Closing the browser.
- Opening the website again.

Tasks are stored locally in the user's browser.
